---
title: Quickstart
description: Start two agents, watch their progress, and return to either conversation.
---

Give two agents separate workspaces, then move between their conversations.

Before you begin, [install CoCo](../installation/) and run `cocod` in another
terminal. Leave it running throughout this walkthrough.

## Register your repository

Inside a Git repository with at least one commit:

```bash
coco repo add .
```

You can safely repeat this command.

## Start two agents

```bash
coco create fix/login -s "Investigate the login flow and fix a bug if you find one"
coco create review/cache -s "Review the cache and report possible correctness issues"
```

Choose instructions that fit your project. Each agent gets a separate
checkout and conversation. The commands return once Codex accepts the work.

## Watch their progress

```bash
coco status -f
```

The display updates as agents work, become ready, or need your input.
Press Ctrl+C to leave the display; their work continues.

When a workspace needs approval or an answer, status shows a
`coco decide <decision-id>` command. Run it in another terminal, or open
the conversation as shown below.

## Jump into a conversation

```bash
coco jump fix/login
```

This opens the workspace in the Codex terminal UI. Read its response, answer
questions, and continue working. Use `/quit` or `/exit` to leave the UI
while keeping active work running.

Run `coco jump` without a name to choose a workspace interactively.

## Continue from your terminal

Once the agent is ready, send another instruction:

```bash
coco send fix/login "Add a regression test for the change" --wait
```

`--wait` prints the response when the turn finishes. Omit it when you want
the command to return while the agent works.
