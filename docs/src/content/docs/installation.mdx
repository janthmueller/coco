---
title: Installation
description: Install CoCo with Cargo or Nix and start its coordinator.
---

CoCo runs on Linux and macOS and uses your existing Codex login and
configuration. The current repository version is tested with Codex 0.154.0.

You need Git and a configured `codex` command on your `PATH`.

## Install with Cargo

With Rust 1.98.1 or newer, install the current repository version:

```bash
cargo install --locked --git https://github.com/janthmueller/coco codex-coordinator
```

For the latest published alpha instead:

```bash
cargo install --locked codex-coordinator
```

These docs describe the repository version; newly added commands may appear
here before the next published alpha.

The package installs `coco`, `cocod`, and `coco-mcp`, normally into
`~/.cargo/bin`. Make sure that directory is on your `PATH`.

## Install with Nix

With flakes enabled:

```bash
nix profile add github:janthmueller/coco
```

This provides the same three commands and supplies the build toolchain.

## Build from a checkout

```bash
git clone https://github.com/janthmueller/coco.git
cd coco
cargo install --path . --locked
```

With Nix, you can use `nix develop -c cargo install --path . --locked` for
the final command.

## Start CoCo

Check your installation:

```bash
coco --version
codex --version
```

Start the coordinator in its own terminal:

```bash
cocod
```

Leave it running while using CoCo. It keeps agent work running when you leave
a CLI command or the Codex UI. Installation currently leaves background-service
setup to you.

Stopping `cocod` interrupts active turns. Saved conversations, workspaces,
and files remain available when you start it again.

Continue with the [quickstart](../getting-started/). If startup fails, use
[Troubleshooting](../reference/current-limitations/).
