---
title: Codex profiles
description: Prepare a workspace with a named set of Codex settings.
---

Use a profile when one workspace needs different Codex settings, such as a different
reasoning effort, sandbox, or approval policy.

## Define a profile

Add it to your Codex configuration file, normally `~/.codex/config.toml`:

```toml title="~/.codex/config.toml"
[profiles.dev]
model_reasoning_effort = "high"
approval_policy = "on-request"
sandbox_mode = "workspace-write"
```

Use keys supported by your installed Codex version.

## Use it for a workspace

```bash
coco create refactor/cache \
  --base main \
  --profile dev

coco send refactor/cache "Refactor the cache and run its tests"
```

Without `--profile`, CoCo uses Codex's default configuration. The chosen
profile applies when the workspace is created; changing the profile file later
does not reconfigure an existing workspace.
