## Before you begin

You need:

- Linux or macOS;
- Git and Nix with flakes enabled;
- a configured `codex` command on `PATH`;
- a Git repository with at least one commit.

CoCo does not publish release binaries yet, so this guide installs it from a
source checkout.

## Install CoCo

From the CoCo checkout:

```bash
nix develop
cargo install --path . --locked
```

## Start CoCo

Keep CoCo running in its own terminal:

```bash
cocod
```

Stop it later with <kbd>Ctrl</kbd>+<kbd>C</kbd>.

## Add a repository

Open another terminal in the repository where Codex should work:

```bash
coco repo add .
```

Adding a repository is safe to repeat. It does not create a commit, branch, or
worktree.

## Prepare your first workspace

The repository must be clean before creating a workspace.

```bash
coco create feat/first --base HEAD
```

CoCo creates a separate worktree, branch, and Codex conversation. Your current
checkout remains unchanged, and no work starts yet.

## Send work and follow it

```bash
coco send feat/first "Inspect this project and suggest one focused improvement"
coco status feat/first --follow
```

If the status says Codex is waiting, run the `coco decide …` command it prints
and choose an answer.

When the workspace is ready again, enter its worktree and existing conversation in
the Codex terminal UI:

```bash
coco jump feat/first
```

You can also create and start in one step:

```bash
coco create feat/second -s "Review the command-line interface"
```

Continue with [Working with workspaces](../guides/workspaces/) or see the complete
[command reference](../reference/cli/).
