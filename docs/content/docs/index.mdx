---
title: CoCo
description: Run several Codex workspaces without mixing their files or losing track of their results.
---

CoCo stands for **Codex Coordinator**. A CoCo workspace keeps one Codex
conversation together with its own Git worktree and branch.

Use it when you want Codex to investigate or change several things at once
without mixing their files or disturbing your own checkout.

## A typical workflow

```bash
coco repo add .

coco create fix/login --base main
coco send fix/login "Fix the login redirect and run the relevant tests"

coco status fix/login --follow
```

`create` prepares `coco/fix/login`, its separate checkout, and its Codex
conversation. Nothing runs until `send`. Use `jump` whenever you want to open
that same conversation in the Codex terminal UI.

<Callout type="warn" title="Early preview">
  CoCo currently installs from source and is intended for supervised local use.
  Read the current limitations before relying on it for unattended work.
</Callout>
