# Project knowledge bundle

Internal product and engineering knowledge for maintainers and coding agents.
The bundle follows the progressive-disclosure approach of the
[Open Knowledge Format v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md).

## Start here

- [Product knowledge](product/) - Routes to the normative CoCo v0 behavior,
  lifecycle, safety constraints, and acceptance criteria.
- [Engineering knowledge](engineering/) - Routes to the daemon topology,
  adapters, persistence model, state transitions, and delivery slices.
- [Documentation boundaries](documentation.md) - Defines the audiences,
  responsibilities, and technology direction for repository documentation.
- [Branch working documents](work/) - Explains the required one-document-per-
  branch workflow and links active or historical task records.
- [Knowledge update log](log.md) - Records significant structural and semantic
  changes to this bundle, newest first.

## Reading policy

Read only the concepts relevant to the current task. Public behavior and tests
remain authoritative; this bundle explains durable intent, constraints, and
decisions around that behavior.
